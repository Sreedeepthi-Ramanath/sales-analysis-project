# Sales Analysis Project

## Objective
Analyze retail sales data to identify trends and business insights.

## Tools Used
- Python
- pandas
- matplotlib
- seaborn

## Key Insights
- Highest sales region
- Best-selling products
- Monthly sales trends

## Project Structure
- data/
- notebooks/
- visuals/

## Key Business Insights

- West region generated the highest revenue
- Technology category showed strongest profitability
- Sales peaked during November and December
- Certain products generated high sales but low profit margins
